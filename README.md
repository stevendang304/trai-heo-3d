# Mô hình 3D trại heo 600 nái + 60.000 heo thịt

Mô hình three.js tương tác, chạy trực tiếp trên trình duyệt.

- `index.html`: phiên bản 2 (cải tiến), gồm 4 khu thịt độc lập, luồng một chiều, phân vùng sạch/bẩn và mô phỏng hoạt động.
- `v1/index.html`: phiên bản 1, dựng theo brief gốc.

Kích thước và vị trí chỉ mang tính minh hoạ, không phải bản vẽ thiết kế.
