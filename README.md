# Mô hình 3D trại heo (three.js)

Mô hình tương tác, chạy trực tiếp trên trình duyệt.

- `index.html`: **v3**, 600 nái + 6.000 heo thịt. Trại khép kín, sản xuất theo nhóm tuần, mô phỏng hoạt động của người và xe.
- `v2/`: 600 nái + 60.000 heo thịt, phương án cải tiến với 4 khu độc lập.
- `v1/`: 600 nái + 60.000 heo thịt, dựng theo brief gốc.

Kích thước và vị trí chỉ mang tính minh hoạ, không phải bản vẽ thiết kế.
